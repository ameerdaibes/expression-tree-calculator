# Expression Tree Calculator

A C program for validating arithmetic expressions, converting infix notation to postfix, evaluating expressions, and constructing expression trees.

## Features

- Reads multiple arithmetic expressions from an input file
- Checks whether each expression is valid
- Detects issues such as:
  - unmatched parentheses
  - missing operators
  - malformed expressions
- Converts valid infix expressions to postfix notation
- Evaluates postfix expressions
- Builds an expression tree for valid expressions
- Supports tree traversal in:
  - Inorder
  - Preorder
  - Postorder
- Writes processed results to an output file

## Data Structures & Concepts

- Stacks
- Expression Trees
- Tree Traversal
- Infix to Postfix Conversion
- Postfix Evaluation
- File I/O
- Expression Validation

## Technologies

- C
- Standard C Libraries
- File-based input/output

## Example

Input:

```text
4+(16-11)+6*[8+(9+7)-3]
4+(7-5)
```

The program can validate the expressions, convert them to postfix notation, evaluate the results, and represent them using expression trees.
